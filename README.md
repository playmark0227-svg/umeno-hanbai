# 梅乃寿司 販売管理 ― プレビュー

仕出し寿司店で 20年以上動いていた Access 2000 の販売管理システムを、
ブラウザで動くソフトに置き換えたもの。その**画面を触って確かめるための公開版**です。

**▶ <https://playmark0227-svg.github.io/umeno-hanbai/>**

はじめて開くと「サンプルで試す」を選べます。架空の得意先・商品・売上が入り、
一通りの操作を試せます。

---

## ⚠ このリポジトリについて

- 入っているのは **画面のプログラムだけ**です。
- 得意先の名前・住所・電話・売上金額といった**実際のデータは一切含みません**。
  実データは Firestore にあり、ログインした人だけが見られます。
- プレビューで表示される得意先・住所・電話・金額は**すべて架空**です。
  実在の店・人・取引とは関係ありません。

## プレビューでのデータの持ち方

保存先を設定していないので、**開いたブラウザの中（IndexedDB）だけ**に入ります。
サーバーには何も送りません。消すには、そのブラウザの閲覧データを削除してください。

本番では Firebase（Firestore ＋ ログイン ＋ Hosting）につなぎ、
どのパソコンからでも同じデータが見えるようにします。

## さわってみるところ

| 画面 | 見どころ |
|---|---|
| 売上伝票 → ＋新規 | 商品番号を入れると品名・単位・単価が入り、数量で金額と消費税が決まる |
| 請求書 | 月を選んで「集計する」→ 行をクリックすると請求書の形で出る |
| 売掛残高一覧 | 誰にいくら残っているか。前受け（もらいすぎ）は分けて表示 |
| 得意先元帳 | 一社ぶんの売上と入金を日付順に、残高つきで |
| 日報 / 月報 | 一日の売上、年ごと・得意先ごとの売上と前年同期比 |

キーは Access に合わせてあります。`Enter` 次の欄／`F4` 一覧から探す／`F1` 登録／`F12` 戻る。
右上の **小・中・大** で全体の文字が大きくなります。

## 作り

ビルド作業なし・依存ライブラリなしの素の HTML / CSS / JavaScript（ES modules）。
Firebase SDK だけ、保存先を設定したときに動的 import します。

```
index.html
css/app.css          意匠（藍・白木・朱／明朝見出し／青海波）
js/app.js            起動・画面切替・ログイン
js/store.js          データ層（Firestore ⇄ IndexedDB）＋残高と請求の計算
js/ui.js             画面部品
js/util.js           日付・金額・かな・消費税・締日
js/demo.js           サンプルデータ（架空）
js/views/*.js        画面ごと
```

### 設計で変えたところ

Access は得意先マスタに「繰越額・当月売上額・入金額」を**持ち回り**、
「日次更新」「年次繰越」で書き換えていました。走らせ忘れや二重実行で狂う構造です。

Web 版は持ち回りをやめ、**毎回伝票から積み直します**。

```
売掛残高 = 移行時残高 + Σ掛売(税込) − Σ入金
請求額   = 繰越 − 入金 − 入金値引 + 当月売上 + 消費税 − 値引
```

おかげで日次更新・年次繰越という作業自体が無くなり、「確定」を押し忘れても
金額がずれません。
